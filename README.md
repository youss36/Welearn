## 📌 Executive Summary
**WE LEARN CONSULTING** is an agency dedicated to assisting students with higher education abroad (Germany, Turkey, Hungary, Spain, China, Malta, etc.)[cite: 9]. This **Internal CRM Platform** was designed and developed to centralize university data, automate lead tracking, manage student application pipelines, handle influencer referral links, and track commissions seamlessly[cite: 9, 10, 11, 12].

---

## 🚀 Key Modules & Architecture

### 1. 🌍 Destinations & University Database
- **Study Destinations:** Built-in repository for multiple countries and partnering institutions[cite: 9].
- **University Management:** Full CRUD operations for universities, programs, degrees (Bachelor, Master, MBA, PhD), languages, tuition fees, scholarships, and admission requirements[cite: 9].
- **Advanced Filtering Engine:** Real-time multi-criteria filtering by Country, City, Budget, Field of Study, Language, Degree, and Scholarship Availability[cite: 10].
- **Data Export:** Instant export of university lists to PDF/Excel formats[cite: 9].

### 2. 📊 Lead Management & Pipeline Tracking
- **Automated Lead Capture:** Manual insertion + public lead generation form integration[cite: 10, 12].
- **13-Stage Conversion Pipeline:**
  `1. New Lead` ➔ `2. Contacted` ➔ `3. Interested` ➔ `4. Docs Requested` ➔ `5. Docs Received` ➔ `6. University Selected` ➔ `7. Application Submitted` ➔ `8. Admission Obtained` ➔ `9. Payment Made` ➔ `10. Visa Pending` ➔ `11. Visa Granted` ➔ `12. Departure Confirmed` ➔ `13. File Closed`[cite: 10].
- **Audit Log:** Complete step-by-step history tracking for every lead state change[cite: 10].

### 3. 📂 Document Vault
- Centralized, secure document storage with live preview/download capabilities for Passports, Diplomas, Transcripts, CVs, Cover Letters, and Language Certificates[cite: 11].

### 4. 🤝 Partner & Influencer Portal
- **Unique Referral Links:** Automatic lead association via tracking links (`welearn.com/apply?ref=partner001`)[cite: 11].
- **Private Dashboard:** Influencers can independently monitor generated leads, active students, admissions, and confirmed departures[cite: 11, 12].
- **Automated Commission Engine:** Real-time estimation and validation of commission payouts based on conversion performance[cite: 12].

### 5. 👥 Role-Based Access Control (RBAC) & Notifications
- **Admin:** Complete system control, user management, and configuration[cite: 13].
- **Counselor:** Lead management, program consultation, and application updates[cite: 13].
- **Automated Alerts:** Email notifications triggered on critical events (New Lead, Admission Secured, Visa Granted)[cite: 13].
